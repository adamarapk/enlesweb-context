Gunakan [set screenshot hasil build audit](../screens-as-is-2026-10-21/README.md) sebagai referensi tampilan terkini. Set tersebut berisi seluruh 43 varian pada lebar 390 dan 1280 piksel, lima halaman pada kedua lebar itu, tampilan gelap beranda, dan panel composer.

Skrip [capture.mjs](../../scripts/capture.mjs) saat ini menulis ke folder ini. Capture audit memakai salinan sementara dengan tujuan output terpisah agar file yang sudah berubah tidak tertimpa.
